# Window Images

Generated for this project using Higgsfield / GPT Image 2, high quality, 2K, 16:9, September 24, 2026. These are creative visualizations, not mission photography. Served as optimized WebP derivatives at 1920 pixels wide; no generated typography. Composited behind the original live 21st lunar component.
